## 📦 What Can You Do With vrma-lab?

### 🎭 Edit Existing VRM Animations
VRM is a popular file format for 3D characters (like the ones you see in games or virtual worlds). With vrma-lab, you can open a VRM animation and tweak movements, poses, timings, and more—all visually.

### 🦴 Convert FBX to VRMA Locally (Your Files Never Leave Your Computer)
Do you have animations in FBX format (a common 3D file type)? vrma-lab can convert them to VRMA format **right on your own device**. This is a "local-first" process, meaning your files are never uploaded to any server. Your work stays private.

### ✅ Export Validated Files
When you're done editing, you can export your animation with confidence. vrma-lab checks your export to make sure it’s valid, so you won’t run into errors when you try to use the file in other programs.
